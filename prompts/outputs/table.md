# TABLE OUTPUT FORMATTER

## TUJUAN

Formatter ini memastikan seluruh data berbentuk tabel memiliki format yang konsisten, mudah dibaca, dan kompatibel dengan Markdown serta platform AI.

Gunakan tabel hanya apabila memang lebih efektif dibandingkan paragraf atau daftar.

---

# KAPAN MENGGUNAKAN TABEL

Gunakan tabel untuk:

- Daftar lowongan kerja
- Daftar perusahaan
- Daftar HRD
- ATS Keyword
- Skill Mapping
- Perbandingan CV
- Perbandingan Cover Letter
- Checklist Validator
- Quality Report
- Riwayat Lamaran
- Timeline Rekrutmen

Jangan gunakan tabel untuk:

- Surat Lamaran
- Cover Letter
- Email
- Motivation Letter
- Personal Statement

---

# FORMAT TABEL

Gunakan Markdown Table standar.

Contoh:

| Kolom 1 | Kolom 2 |
|----------|----------|
| Data | Data |

---

# ATURAN PENULISAN

Header harus jelas.

Gunakan Title Case.

Contoh:

Nama Perusahaan

Posisi

Lokasi

Status

Tanggal

Jangan menggunakan:

NAMA PERUSAHAAN

nama perusahaan

---

# ISI SEL

Isi harus singkat.

Maksimal 50 karakter apabila memungkinkan.

Apabila terlalu panjang,

ringkas.

---

# PENYELARASAN

Teks:

Rata kiri.

Angka:

Rata kanan apabila didukung.

Status:

Gunakan teks sederhana.

Contoh:

Diproses

Interview

Ditolak

Diterima

---

# NILAI KOSONG

Jika data tidak tersedia,

gunakan:

—

Jangan gunakan:

NULL

None

Unknown

Lorem Ipsum

---

# PENGURUTAN

Apabila memungkinkan,

urutkan berdasarkan:

Tanggal terbaru

Status

Nama Perusahaan

Posisi

---

# LARANGAN

Jangan membuat tabel yang memiliki:

- Sel kosong berturut-turut
- Header duplikat
- Kolom tanpa nama
- Baris duplikat
- Markdown rusak
- Kolom yang tidak relevan

---

# VALIDASI

Periksa:

☐ Header lengkap

☐ Jumlah kolom konsisten

☐ Tidak ada sel rusak

☐ Markdown valid

☐ Tidak ada duplikasi

☐ Mudah dibaca

---

# OUTPUT

Output HARUS berupa tabel Markdown yang valid.

Contoh:

| Perusahaan | Posisi | Lokasi | Status |
|------------|--------|---------|---------|
| PT ABC | Operator Produksi | Sidoarjo | Diproses |
| PT XYZ | Teknisi | Gresik | Interview |

Jangan menambahkan penjelasan di dalam tabel.

Apabila diperlukan, berikan penjelasan setelah tabel selesai.
