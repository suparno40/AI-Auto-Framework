# TASK

Create a professional cover letter based on:

- User CV
- Job Description
- Company Information

## REQUIREMENTS

- Personalize for each company.
- Highlight relevant experience.
- Mention key skills from the Job Description.
- Keep between 250–400 words.
- Use professional language.
- Never fabricate qualifications.

## OUTPUT

- Greeting
- Opening
- Professional Background
- Relevant Skills
- Closing
- Signature
